# PSO プロトコルコマンド リファレンス

このドキュメントは、PSO クライアントと newserv サーバーの間で使われるネットワークプロトコルのコマンド（オペコード）を説明します。

## 概要

コマンドは 1 バイトのオペコード（0x00–0xFF）で識別されます。同じコマンドでも、ゲームのバージョンによって処理が異なる場合があります。サーバーは 14 のゲームバージョンに対応しています：

| 列 | バージョン |
|------|------|
| 1 | PC_PATCH |
| 2 | BB_PATCH |
| 3 | DC_NTE |
| 4 | DC_112000 |
| 5 | DCV1 |
| 6 | DCV2 |
| 7 | PC_NTE |
| 8 | PC |
| 9 | GCNTE |
| 10 | GC |
| 11 | EP3TE |
| 12 | EP3 |
| 13 | XB |
| 14 | BB |

### コマンドヘッダーの形式

- **DC/GC/XB（PSOCommandHeaderDCV3）：** 4 バイト — command(1)、flag(1)、size(2)
- **PC（PSOCommandHeaderPC）：** 4 バイト — size(2)、command(1)、flag(1)
- **BB（PSOCommandHeaderBB）：** 8 バイト — size(2)、command(2)、flag(4)

### ソースコードの命名規則

- `C_` 接頭辞：クライアント → サーバー（クライアントが送信）
- `S_` 接頭辞：サーバー → クライアント（サーバーが送信）
- `SC_` 接頭辞：双方向（どちらの方向でも使用）

## パッチサーバーのコマンド（PC_PATCH / BB_PATCH のみ）

| オペコード | 方向 | 名前 | 説明 |
|--------|-----------|------|-------------|
| 0x02 | S→C | ServerInit_Patch | パッチ接続のサーバー初期化 |
| 0x02 | C→S | （応答） | クライアントがパッチサーバーの初期化を確認 |
| 0x04 | S→C | （ログイン要求） | サーバーがユーザーのログイン情報を要求 |
| 0x04 | C→S | Login_Patch | クライアントがユーザー名・パスワード・メールアドレスを送信 |
| 0x06 | S→C | OpenFile_Patch | パッチ対象のファイルを開く |
| 0x07 | S→C | WriteFileHeader_Patch | パッチ中にファイルヘッダーを書き込む |
| 0x08 | S→C | CloseCurrentFile_Patch | パッチ中の現在のファイルを閉じる |
| 0x09 | S→C | EnterDirectory_Patch | パッチ中にディレクトリへ入る |
| 0x0C | S→C | FileChecksumRequest_Patch | クライアントにファイルのチェックサムを要求 |
| 0x0F | C→S | FileInformation_Patch | クライアントがファイルのチェックサムとサイズを返す |
| 0x10 | C→S | （全チェックサム完了） | クライアントがすべてのチェックサム要求への応答を完了 |
| 0x11 | S→C | StartFileDownloads_Patch | ファイルのダウンロードを開始 |
