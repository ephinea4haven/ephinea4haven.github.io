# 道具图鉴 MVP

预览入口：`/data/items.html`。本轮经用户要求制作可运行 MVP；目前只收录 12 件样本，并非完整目录。

## 已实现

- 8 件光剑系武器、1 件铠甲、1 件盾牌、2 件插件；7 张天幻原始截图，保留水印。
- 中英日名称与道具代码搜索，类别、职业、星级、截图筛选，名称／星级／武器基础 ATP 上限排序，8 件一页。
- 筛选和分页存入 URL；12 个预渲染详情地址，返回列表保留条件。
- 手机单列条目、可展开筛选、属性与职业限制、来源和获取入口。

## 数据与图片

`src/app/item-catalog/catalog.json` 保存英文身份、属性、来源、核对日期及图片映射；`catalog.ts` 从生成的 `ITEM_TRANSLATIONS` 获取权威显示名称，缺失身份直接报错。新增名称仍须先核对 `../droptable/i18n_names.json` 并运行 `npm run sync:i18n`。

武器来源为 Ephinea Wiki 各单件页面及 https://wiki.pioneer2.net/w/Sabers 。职业限制同时核对 http://pso.ffsky.cn/saber.htm 的职业列表；Elysion 的限制由 Ephinea 单件页面明确说明。图片 URL 与原页面写入各条目的 `imageSource`、`imagePage`；本地文件为下载的原始 GIF，未裁切、重绘或去除水印。缺图明确显示“暂无截图”。

每件武器基础 ATP 与最大磨数下 ATP 分开展示；后者是基础范围加上磨数的两倍，未计入其他条件。防具展示个体取值范围。Red Ring 的 DFP/EVP 已包含其固定加成。V502 效果以倍数表示，不与命中率或百分点混淆。

获取方式是概要及对应上游入口，未复制动态掉落概率，也未承诺当前活动供应。图鉴样本只覆盖选定的核心字段和说明，仍需继续补充套装、合成及高级机制资料。

图鉴首次使用 Angular RouterLink 在列表与详情间导航，新增共用路由代码后，初始产物约 301 kB（未压缩）。Angular 初始包上限由 300 kB 调整至 310 kB，警告线为 300 kB；独立的 gzip 总量、chunk 和路由预算保持不变。道具数据和界面仍随功能路由延迟加载。
