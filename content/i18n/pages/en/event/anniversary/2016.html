2016 · Ephinea’s first anniversary event

The first event was called Ephinea Summer Event, establishing the basic format of badges, event shops and server milestones.

11 August–1 October1st AnniversarySummer Event
This year’s core features
  • Bronze, Silver and Gold Badges drop from enemies throughout the game and can be exchanged at the Summer Badge Shop.
  • Extremely rare Platinum Badges can be given to Guide for top prizes.
  • Kills in MA4 and Christmas Fiasco count towards server milestones, gradually unlocking server rewards.
  • Some milestone rewards require personal kill counts and are distributed per account after the event.
