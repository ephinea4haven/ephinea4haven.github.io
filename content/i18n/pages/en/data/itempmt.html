ItemPMT (Item Parameter Table) is the item parameter table shared by the PSO client and server. For every weapon, frame, barrier, unit, Mag and consumable, it defines base stats, name indexes, equipment requirements, descriptions and appearance models. ItemPT and ItemRT determine when items drop and at what probability; they consult ItemPMT for the detailed parameters of the item itself.

Overview

ItemPMT is the game’s item dictionary. Given an item ID, it supplies:

  • Display name (an index into TextEnglish/TextJapanese)
  • Model and texture
  • Category (weapon/frame/barrier/unit/Mag/consumable/Technique/…)
  • Base stats (weapon ATP/ATA, frame DFP/EVP, barrier resistances…)
  • Equipment restrictions (class flags, ATP/MST/ATA and level requirements)
  • Grind limit, star rarity, whether the item can be sold and base sale price

This table is used when the client reads saved items, when players inspect item details and when the server checks equipment eligibility.

Files and versions

ItemPMT is a PRS-compressed binary file, with different versions for different PSO releases:

  • ItemPMT-bb-v4.prs — official PSOBB / Ephinea
  • ItemPMT-gc-v3.prs — GameCube (Episode I & II)
  • ItemPMT-gc-ep3.prs — Episode III card game
  • ItemPMT-xb-v3.prs — Xbox
  • ItemPMT-pc-v2.prs — PC v2
  • ItemPMT-dc-v1.prs / ItemPMT-dc-v2.prs — Dreamcast v1/v2
  • There are also NTE (Network Trial Edition) and November 2000 prototype versions.

Weapons

Weapon fields fall into three broad groups:

Identity and classification

  • ID: unique item number, also selecting the name text index
  • Model / Texture: 3D model and texture
  • Type / Subtype: parent type and subtype, such as // within the saber family
  • Class Flags: eligible classes, one bit for each of the 12 classes (HUmar/HUnewearl/HUcast/…)

Combat fields

  • ATP Min / ATP Max: base ATP range; the actual value is random within this range
  • ATA: weapon ATA bonus
  • Max Grind: maximum grind (+9 means 9)
  • Photon: photon type, determining melee/ranged/Technique category and combo behaviour
  • Special: default special ID (references Special attack table)

Equipment requirements

  • ATP Required: minimum ATP to equip
  • MST Required: minimum MST to equip
  • ATA Required: minimum ATA to equip

Frames (Armor / Frame) and barriers (Shield / Barrier)

Frames and barriers share a structure but are stored in separate subtables. Each entry contains:

  • DFP / EVP: base defence and evasion, with a min–max range for random variation
  • Class Flags: eligible classes
  • Required level: minimum level to equip
  • Maximum DFP / EVP bonus: maximum increase through frame upgrades (frame +N)
  • Unit slots: always 0 for barriers; 0–4 for frames (rare frame slots are selected by ItemPT, not fixed)
  • Five elemental resistances: EFR / EIC / ETH / EDK / ELT (fire/ice/lightning/dark/light)

Units

Unit entries are relatively simple:

  • Class Flags: eligible classes
  • Stat Bonus: the stat and amount added (HP, TP, ATP, DFP, ATA, EVP, LCK, MST…)
  • Plus/minus threshold: units marked with / signs (such as , HP/Resurrect): activation chance or cooldown
  • Star rarity: determines common versus rare units

Some units use behavioural checks rather than numeric bonuses, such as , /, . Their effects are hard-coded by item ID rather than stored as numeric fields in ItemPMT.

Mags

Mag parameters are a distinctive part of ItemPMT. Each Mag entry contains:

  • Model ID: evolved appearance, dependent on DEF/POW/DEX/MIND and the owner’s class group
  • Photon point cost (feed table): stat changes and amounts for each food item
  • Photon Blast group combinations: which PBs can occupy the three slots

The Mag feeding rules form a large table in ItemPMT: 8 feeding tables × 11 foods; each Mag type points to one of the tables, and each cell specifies changes to DEF/POW/DEX/MIND/SYNC/IQ.

Consumables (Tools)

Tool entries are the simplest, primarily containing:

  • ID and Name index
  • Use effect ID (the game handles healing, status recovery, teleporting and so on by ID)
  • Stack limit (Stack Max): maximum per inventory slot; for example, recovery items and stack to 10, to 99.
  • Can be sold / Base sale price
  • Star rarity: for example, is a consumable with a star rating

Technique disks belong to Tools but have a different small structure: Technique ID plus level, with a fixed stack limit of 1.

Special attack table

Weapon specials (Charge / Spirit / Berserk / Geist / Hell / Demon’s / Arrest / Chaos / Blizzard / Burning…) have their own table referenced by ID in ItemPMT. Each entry includes:

  • Name index (“Charge”, “Berserk”, etc.)
  • Star rarity: common-weapon special generation rolls a star tier, then selects an ability in that tier
  • Activation parameters: chance, cost (MST/HP/etc.) and additional damage

Where do common-weapon specials come from?
Instead of reading a weapon’s Special field directly, ItemPT generates a star tier (0–5) based on area, then selects a matching entry in ItemPMT. So a weapon found in the Mines may carry a 1★ Draw, while the same model found in the Ruins may carry a 4★ Gush: the available pool differs by area.

Other subtables

Alongside the main item entries, ItemPMT has smaller auxiliary tables for various game systems:

Combining and upgrading (Item Combination Table)

Recipes record used item × equipped target × result, with additional constraints:

  • Required Mag level, weapon grind, character level and class
  • Example uses: converting into , or upgrading a weapon with a specific tool

This table is not the attack combo table. PSO’s N-N-H / N-H-H sequence modifiers are hard-coded in the client. The only combo-related ItemPMT field is each weapon’s one-byte behavior_flags, whose bits include a combo prohibition flag (some weapons can attack only once per sequence).

Tech Boost Table

Technique damage or range bonuses on canes and related weapons. Examples include , which gives Rafoie / Rabarta / Razonde +30% damage, and , which gives Jellen / Zalure +100% range. A weapon’s tech_boost field points to this table.

Special Data / Weapon Effect / Shield Effect

  • Special Data Table: parameters for all specials (Charge/Berserk/Hell/Demon’s…), as described above.
  • Weapon Effect Table: passive effects of equipped weapons, such as HP absorption or resistances.
  • Shield Effect Table: passive effects on barriers, such as regeneration and additional rare-barrier effects.
  • Ranged Special Table: ranged-weapon special behaviour; some specials behave differently on ranged weapons.

Stat Boost Table

Actual bonus data referenced by units. The unit stores a boost ID; this table supplies the stat and amount.

Max Tech Level Table

Technique level caps for each class. For example, Forces can learn Lv30 Rafoie while Hunters are described here as capped at Lv15. Disks above a class’s cap cannot be used.

Photon Color / Weapon Range / Star Value

  • Photon Color Table: photon blade colours, with an RGB combination for each photon type.
  • Weapon Range Table: weapon attack reach and hit-range parameters.
  • Star Value Table: maps item IDs to star ratings, determining the ☆ count beside item names.

Unsealable / Unwrap

  • Unsealable Table: the result of unsealing weapons such as , .
  • Unwrap Table: possible contents of gift boxes such as and .

Sale Divisor / V1 Replacement

  • Weapon Sale Divisor / Non-Weapon Sale Divisor: item-specific divisors used to calculate shop sale prices.
  • V1 Replacement Table: replaces PSO v1 item IDs with their BB equivalents.
