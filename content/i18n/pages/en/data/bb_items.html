Weapon attributes

First byte of the four-digit attribute code (PSPS):

  • 01 = Native (Forest)
  • 02 = A.Beast (Caves)
  • 03 = Machine (Mines)
  • 04 = Dark (Ruins)
  • 05 = Hit

Second byte of the four-digit attribute code (PSPS):

  • 00 = 0% | 0A = 10% | 14 = 20%
  • 32 = 50% | 3C = 60% | 64 = 100% | 7F = 127%

Frames / barriers

/makeitem VVVVVV00,000SDDDD,EEEE0000,,
Parameter Description
VFrame ID (hexadecimal)
SNumber of slots
DDFP bonus (must not exceed the maximum)
EEVP bonus (must not exceed the maximum)

Frame slots

  • 1 = 1 slot / 2 = 2 slots / 3 = 3 slots / 4 = 4 slots

Mags

Use magmaker.exe

Example magmaker.exe output:
78C80710
0A271DAF
257F0257
D3C83F02

Enter in PSO:

/makeitem 023FC8D3,57027F25,AF1D270A,78C80710

Tools

/makeitem VVVVVV00,00AA0000,,,
Parameter Description
VTool ID (hexadecimal)
AQuantity (hexadecimal)
Note: set $setitem4 to 00000000, or use $resetitem before $setitem2 and $setitem3 to reset everything.

Units

/makeitem VVVVVV00,000000SS,SS000000
Parameter Description
VUnit ID (hexadecimal)
SSuffix (hexadecimal)

Unit suffixes

  • 0100 = + | 0300 = ++ | FFFF = - | FEFF = --

Parameter Description
VTechnique value
LTechnique level (hexadecimal)
