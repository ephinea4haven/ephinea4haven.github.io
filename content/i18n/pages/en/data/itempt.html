ItemPT (Item Pattern Table) is PSO’s common-drop rule table. When an enemy or box drops a non-rareitem, it determines the type, attributes, grind, special and Meseta amount. Rare drops are controlled by ItemRT ; base item parameters such as ATP, ATA and level requirements come from ItemPMT . ItemPT chooses what drops and the generated item’s variations.

Overview

A common-drop event follows roughly this sequence:

  1. Check whether anything drops: each enemy type has a drop probability of 0–100%. This first check determines whether the event produces a drop.
  2. Choose the item category: use the item category table for the enemy/box area to select Weapon/Frame/Barrier/Unit/Consumables/Meseta .
  3. Choose the specific item: use the category’s subtable, such as the 26-entry consumable probability table or weapon type/subtype table.
  4. Generate additional properties: for weapons, determine grind (+0 to +9), attributes (Native / A.Beast / Machine / Dark / Hit) and special (Charge / Spirit / Berserk…).

ItemPT stores subtables by difficulty × area, so item distributions differ between difficulties and areas. Familiar patterns such as Mechguns in Mines and high attributes in Ruins come from these tables.

Category-based common drops

Besides consumables, ItemPT handles non-rare drops in these categories:

  • Weapon (Weapon): selected by type (sword/handgun/mechgun/shield/…) and subtype. The area determines the available subtype range.
  • Frame (Armor / Frame): tier depends on area, the upgrade probability table and type bias.
  • Barrier (Shield / Barrier): follows the frame rules.
  • Unit (Unit): the area determines the maximum star rating (unit_max_stars_table).
  • Empty: some area/enemy combinations specify no drop.

Base values for all common items, such as frame DFP/EVP and weapon ATP ranges, come from ItemPMT; ItemPT only chooses which item drops.

Weapon attribute generation (Bonus)

When ItemPT selects a common weapon, attribute generation determines its 0–3 bonuses.

Generation order

Attribute generation proceeds through area probability → pattern → attribute value :

  1. Area probability: the area determines the chances of Native / A.Beast / Machine / Dark / Hit.
  2. Pattern: determines the number of attributes and each attribute’s tier.
  3. Attribute value: look up the pattern’s percentage table to obtain each bonus value, positive or negative.

A common weapon can have at most three attributes (weapons limited to two attributes, such as / , can have only two). If the same attribute is selected twice, the second becomes None, so three useful bonuses must all be different.

Meseta

ItemPT also manages Meseta drops, using separate subtables:

  • For enemies, the Meseta range depends on the enemy type, with a min ~ max interval sampled at random.
  • For boxes, the Meseta range depends on the area, each with its own min ~ max).
  • Meseta and item drops are separate decisions. An event yields an item, Meseta or nothing.

Data structures

The ItemPT binary format nests Episode × difficulty × area × variable parameters. Each difficulty/area subtable has the structure below. Index probability tables do not need to sum to 100: the game sums their entries and takes a random remainder, so they contain relative weights.

Subtable fields

FieldType (size)Description
base_weapon_type_prob_table u8[0x0C] Common weapon type probabilities: 12 entries for the 12 basic types, through .
subtype_base_table i8[0x0C] Base subtype number for each weapon type. A negative value excludes the first N areas; a non-negative value allows all areas.
subtype_area_length_table u8[0x0C] Number of consecutive areas where each subtype appears. For example, starting at −2 with length 4 appears in C1–M1, then switches to .
grind_prob_table u8[9][4] Grind probabilities, indexed by [grind][area offset within subtype] . The offset is the current area minus the subtype’s first area, clamped to 0–3.
armor_shield_type_index_prob_table u8[0x05] Frame/barrier upgrade probabilities. Final frame type = max(area_norm + sample_from_this_table + bias − 3, 0).
armor_slot_count_prob_table u8[0x05] Frame slot probabilities. [77, 17, 5, 1, 0] means 77% for 0 slots, 17% for 1, 5% for 2, 1% for 3 and 0% for 4.
enemy_type_meseta_ranges map⟨Enemy, Range⟨u16⟩⟩ Enemy Meseta min/max intervals, indexed by enemy type.
enemy_type_drop_probs map⟨Enemy, u8⟩ Overall probability of an enemy dropping anything (0–100), separate from the rare check.
enemy_type_item_classes map⟨Enemy, u8⟩ Enemy drop category: 00=weapon / 01=frame / 02=barrier / 03=unit / 04=consumable / 05=Meseta / other=empty.
box_meseta_ranges Range⟨u16⟩[0x0A] Box Meseta ranges indexed by area_norm (10 areas).
box_item_class_prob_table u8[7][10] Box item category probabilities, indexed by [item_class][area_norm] .
bonus_value_prob_table u16[6][0x17] Weapon bonus value probabilities. Dimension 1 is spec (0–5); dimension 2 is the value tier (−10% to +100% in 5% steps, 23 tiers).
nonrare_bonus_prob_spec u8[3][10] Non-rare weapon bonus spec lookup, indexed directly by [bonus_index][area − 1] (not a probability table).0xFF means no bonus in that slot. Rare weapons always use spec 5.
bonus_type_prob_table u8[6][10] Weapon bonus type probabilities. The six rows are None / Native / A.Beast / Machine / Dark / Hit; the ten columns are area − 1. Rare weapons replace area − 1 with a random value from [0, 9] .
special_mult u8[0x0A] Special generation parameter 1: a sampled value of 0 means no special. Otherwise draw [0, special_mult] and truncate to integer W. If W > 3 there is no special; otherwise assign a (W + 1)-star special.
special_percent u8[0x0A] Overall chance of a special on a non-rare weapon, indexed by area − 1.
tool_class_prob_table u16[0x1C][0x0A] Consumable probability table: 28 types × 10 areas, showing where each consumable or material is most likely.
technique_index_prob_table u8[0x13][0x0A] Technique disk type probabilities: 19 Techniques × 10 areas.
technique_level_ranges Range⟨u8⟩[0x13][0x0A] Level range for each Technique in each area. For example, Rafoie reaches a maximum of Lv30 in Ultimate Ruins.
armor_or_shield_type_bias u8 The bias term in the frame upgrade formula, used with armor_shield_type_index_prob_table .
unit_max_stars_table u8[0x0A] Maximum star rating of units dropped in each area.

Sum each column to get its total weight. None accounts for over 60%; A.Beast and Machine increase in Caves and Mines respectively, Dark is concentrated in Ruins, and Hit has only one weight point everywhere. This makes Hit particularly rare.
