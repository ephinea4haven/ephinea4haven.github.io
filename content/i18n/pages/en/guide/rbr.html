RBR quests and non-RBR farming picks

This page condenses two quest tier articles by みどり into a quick reference. The ratings weigh farming items with market value, overall returns and run efficiency. They are the author's own judgement from experience, not an official server ranking.

How current this is: the RBR tiers follow the November 2025 date marked in the original; the non-RBR tiers date from May 2025. Drop tables, quest revisions, prices and new routes can all change the rankings. Before choosing a quest, check the current Ephinea drop charts.

What RBR is

Ragol Boost Road (RBR) picks one quest each week from the candidate lists of Episodes 1, 2 and 4. It rotates every Sunday at 00:00 UTC. Check it under Statistics at the lobby counter, or type /rbr in game.

Party size DAR / RDR / EXP boost
1 player+15% each
2 players+20% each
3–4 players+25% each
  • The RBR boost stacks with the weekly boosts, events and other boosts.
  • RBR itself does not raise the rare enemy rate (RER).
  • Once a quest is on RBR, its normal time limit is removed.
  • Every candidate in an Episode is used once before the next cycle starts, so a quest can repeat two weeks in a row across a cycle boundary.

For the mechanics and the latest candidate list, the reference is Pioneer 2 Wiki: Ragol Boost Road.

How to use these tiers

  • This week's RBR has an S or A quest: usually worth farming first.
  • This week has only B or C: decide by the drop you want and your Section ID.
  • This week's RBR doesn't suit you: farm the non-RBR MAE4 instead, or pick an S or A quest for the item you still need.
  • RER weeks: RBR adds no extra RER, so switch to the rare-enemy routes further down.

Data sources and automation

The objective RBR base data is generated automatically: the RBR source data JSON holds the 58 candidate quests, the Wiki revision, the current rotation, the Tracker state, Ultimate EXP, full enemy counts and notes on conditional counts. The two hand-rated tier charts are stored separately as tier data JSON.

  • Automatic: the candidate pool, boost rules, the Wiki's current rotation, quest EXP, enemy counts, drop-rate links and base expected values.
  • Semi-automatic only: recommended IDs and PD value per run or per hour, which need current prices and measured run times.
  • Still manual: the final tiers, because routes, party coordination, difficulty, failure risk and market liquidity cannot be read off the enemy tables.

/rbr in game is the authority on the server's actual rotation. The Wiki's current-week template can be fetched automatically but may be updated late. The generator checks the date, the Tracker's coverage of all 58 quests, each Episode's current quest and whether the Tracker agrees with the current-week template; if anything is off, it writes a warning instead of silently treating the data as current.
