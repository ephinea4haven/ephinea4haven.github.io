Set up Windows DEP

1. Right-click the This PC icon on the desktop and choose Properties.

2. In the System window that opens, click Advanced system settings.

3. In System Properties → Advanced → Performance , click Settings.

4. In Performance Options , switch to the Data Execution Prevention tab.

Here you can check whether your processor supports DEP:

  • If it does, it says:Your computer’s processor supports hardware-based DEP.
  • If it doesn’t, it says:Your computer’s processor does not support hardware-based DEP. However, Windows can use DEP software to help prevent some types of attacks.

Set compatibility

1. Right-click the game shortcut and choose Properties.

2. Switch to the Compatibility tab.

3. Tick Run this program in compatibility mode for:

4. Choose Windows XP (Service Pack 2).

Set the launcher resolution

If the game still crashes after the first two steps, try adjusting the resolution.

Add the game folder to your antivirus exclusions

If you see messages in the lower-left of the game such as DLL ERROR , follow these steps:

1. Type sec in the Start menu and open

2. Go to Virus & threat protection

3. Open Manage settings

4. Click Add or remove exclusions

5. Add the game’s root folder as an exclusion

That completes the antivirus exclusion for the game folder.
