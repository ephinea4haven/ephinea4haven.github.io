EPHINEA · LAUNCHER GUIDE

Launcher settings guide

From starting the game to adjusting the camera, find every switch in the order the launcher shows it. Control names stay in English, with an explanation beside each so you can follow along with the interface.

How to use it: click OPTIONS to open the settings and use NEXT PAGE/PREVIOUS PAGE to turn pages. A green switch is on and a grey one is off; grey doesn’t necessarily mean it can’t be clicked. The screenshots show this computer’s configuration at the time, not recommended values. Click an image to see it full size.

Main screen and how settings are saved

ControlWhat it does
START GAMEStarts the game; account login and character selection happen in the game.
ENGLISH / 日本語 / CUSTOMChooses how the language resources are updated. CUSTOM is for custom resources, not a built-in Chinese option; the screenshot’s CUSTOM can coexist with the English interface. Switching language saves the current settings and triggers an update check, so if you maintain a custom translation, confirm the selected resource mode.
OFFICIAL SITE / REGISTER / FAQ / DONATEOpen the official website, account registration, FAQ and donation page.
CREDITS / QUITShow the credits / exit the launcher.
CHECK FOR UPDATESChecks for client updates again; it doesn’t restore settings.
MORESaves the launcher settings first, then opens the separate original detailed settings window.
REVERTReloads the saved configuration and discards unsaved changes.
RESET ALLResets many current settings to the program’s initial values, without saving yet; it also resets the language choice to English and the resolution to 1024×768. If you need CUSTOM resources, confirm the language choice before any later save or update. The 3.5.2 reset doesn’t cover every option added later, so it isn’t a complete wipe of all settings.

How do you save?The launcher has no single Save button. START GAME, QUIT, MORE and similar actions write the settings; clicking OPTIONS again only collapses the panel. To undo changes, use REVERT first and then do something that saves. The MORE window has its own Save/Cancel.

01 / OPTIONS

Display, sound and interface

Decide the game window and rendering method first, then adjust the interface size and sound.

Control / meaningWhat it does and notes
ResolutionScreen sizeSets the width, height and aspect ratio of the game image. Custom lets you enter your own width and height; higher resolutions are usually sharper but cost more to draw.
Windowed ModeWindow typeFullscreen is exclusive fullscreen, Windowed is a normal window, and Virtual Fullscreen is borderless fullscreen. A normal window or borderless fullscreen is usually handier when switching apps.
Rain/Laser ScaleRain and laser line scaleScales line effects such as rain and lasers, with 100% as the baseline; it doesn’t change attack damage or hit areas.
Direct3D APIGraphics backendChoose D3D8, D3D9, D3D9on12, D3D11/12 through dgVoodoo, or Vulkan through DXVK. The version in brackets is the translation component’s version, and Custom uses components you provide. Compatibility depends on drivers and the environment; see the graphics backend guide.
Anti-AliasingAnti-aliasingNone turns it off; MSAA smooths geometry edges; SSAA renders at a higher internal resolution and scales down; SMAA post-processes image edges; HSAA combines SSAA and MSAA. Options marked + SMAA add SMAA on top. Higher settings usually cost more; for support by backend see the anti-aliasing notes.
Anisotropic FilteringAnisotropic filteringDisabled or 2×/4×/8×/16×. Sharpens textures on surfaces seen at an angle, such as floors and roads.
BGM / SFXMusic / effects volumeSet the background music and sound effects separately, from 0 to 10; 0 is mute.
DISABLE SKIN SFXTurn off skin soundsTurns off the dedicated sound effects of weapon skins, not all game sound.
HIGH RES HUD / HUD ScaleHigh-res HUD / interface scaleEnabling the high-res HUD shows HUD Scale. A higher value makes the HUD smaller on screen, leaving more space; this doesn’t install high-definition interface textures.
Damage ScaleDamage number scaleOnly changes the size of the damage numbers, not the actual damage.
NO MINIMAP SCALETurn off minimap scale correctionTurns off the high-res HUD’s minimap scale correction. That correction makes different HUD resolutions show the same internal view range and adjusts icon proportions; it doesn’t fix the size of the whole HUD minimap frame. It doesn’t reveal unexplored areas. See the original scaling behaviour and option announcement.
IMEText input supportEnables the client’s input method support for typing Chinese, Japanese and other text; the input methods available come from your environment.
LOW PERFORMANCELow-load runningMakes the client’s main loop give up CPU time more readily, lowering CPU use; it may affect frame pacing. It isn’t network acceleration or a one-click way to lower all graphics quality.
CLASSIC INTRO FMVLegacy opening movie playbackWhen on, the character creation opening uses the old PAE movie and original player; when off, it uses the newer movie playback path. It doesn’t skip the movie. See the official explanation of the two playback methods.

Further sources: staff explanation of Low Performance; HUD Scale versus high-definition interface textures.

Conveniences and visual effects

This page has bank options as well as post-processing and dgVoodoo settings.

Ambient OcclusionAmbient occlusionDisabled/Low/Medium/High; adds shading depth where surfaces meet and in occluded areas. For post-processing effects and their cost see the shader notes.
dgVoodoo ModelPresentation modeAuto, Discard, Sequential, Flip Discard and Flip Sequential are swap chain/presentation methods, not quality levels. They only matter on the dgVoodoo path; see the swap chain notes.
dgVoodoo VRAMVirtual video memoryAuto or 64–4096 MB; sets the video memory dgVoodoo reports to the old game. It doesn’t add physical memory to your graphics card.

03 / OPTIONS

Reminders, camera and text

Camera controls can be set to suit your gamepad and habits. Some controls only appear once the related feature is on.

Control / meaningWhat it does and notes
SDJZ IconSupport status iconsControls how the Shifta, Deband, Jellen and Zalure icons are shown: Normal, Blink or Fade.
Mag AlertMag feeding reminderWhen on, plays a sound when the Mag you carry can be fed.
Mag Alert DelayReminder intervalThe minimum time between two reminder sounds, in seconds, default 30. It isn’t the Mag’s feeding cooldown.
Analog Camera ControlStick camera controlLets the gamepad’s right stick move the camera.
Analog Sensitivity / INVERTCamera sensitivity / invertSensitivity sets how fast the stick turns the camera; INVERT reverses the matching camera direction.
Camera Dead ZoneCamera stick dead zoneIgnores small inputs near the stick’s centre to prevent camera drift; too large reduces the usable range.
ANALOG CAMERA KEYS / TURN LEFT / TURN RIGHTKeyboard camera controlEnables keyboard keys for turning the camera left and right and lets you choose them; the related controls appear with the camera options.
Chase CamAuto-follow cameraEnabled follows automatically; Disabled turns it off, using manual camera or the recentre key; Hybrid pauses auto-follow while you move the camera with the stick; Toggle stays manual after stick input until you press the recentre key.
Font Render MethodText renderingHi-Res (Antialiased) uses antialiased high-resolution glyphs; Hi-Res (ClearType) uses ClearType; Normal uses the plain method. The font itself is chosen in MORE.
Font ResolutionGlyph resolutionAuto or a set glyph rasterization resolution. It affects sharpness and sampling; it isn’t the same as setting all text to that font size.
NUMPAD SHORTCUTSNumeric keypad shortcutsLets the numeric keypad trigger the matching number shortcut bar.
Show Mob DropTarget enemy rare drop displayDisabled turns it off; Drop Only shows the item only; Drop (Current Rate) adds the current rate; Drop (Current & Base Rate) shows both. It appears in the target info area; rates are calculated by the client and may differ by rounding, and it isn’t a prediction of the next drop.
ENHANCED MAP DRAWExtended scene drawingKeeps more scene geometry drawable, reducing gaps from the original draw distance and culling; may add load. Unrelated to minimap exploration or enemy spawns.

Further sources: Camera mode, Mag reminder and font update notes; Scene drawing and target drop display notes.

04 / OPTIONS

Gamepad, pickup and Photon Blast

Move easily mis-pressed pickup and Photon Blast actions onto a layer that needs a held modifier key.

Control / meaningWhat it does and notes
AUTO DETECT ACTIVE GAMEPADDetect current gamepadAutomatically uses the most recently used gamepad, handy for switching between several controllers.
USE XINPUT FOR GAMEPADUse XInputSwitches to the XInput gamepad interface, with hot-plugging and trigger buttons on supported controllers. When on, the three adjustments below appear; non-XInput devices may need mapping.
DeadzoneStick dead zoneFilters small inputs near the stick’s centre, 0–75%.
Axis SnappingDirection snappingMakes inputs close to horizontal or vertical snap to the straight direction more easily, 0–50%.
Trigger ThresholdTrigger thresholdHow far a trigger must be pressed to count, 0–100%.
Item Pickup and Photon Blast UsagePickup / Photon Blast modeDisabled keeps the original behaviour: nearby items may replace the middle slot of the main action bar with pickup, and a full Photon Blast takes over the secondary action bar. The other three require holding a modifier to use pickup, Photon Blast, or both; the original action bar stays when released.
HOLD GAMEPAD BUTTONGamepad modifierLets a gamepad button trigger that action layer; bind it at the bottom of the in-game Options → Pad button config.
HOLD SHIFT KEY / HOLD ALT KEY / HOLD KEYKeyboard modifierChoose Shift, Alt or a specific key. The related controls appear once the pickup/Photon Blast limit is on. These options don’t pick up items or fire Photon Blasts automatically.

Menu controls and gameplay conveniences

Separates menu responsiveness, shortcut menu contents and the options that actually affect single-player combat.

Control / meaningWhat it does and notes
Menu Scroll Repeat DelayMenu repeat delayHow many frames to wait after holding a direction before repeating starts. Default 6 frames, range 1–20; at 30 FPS, 6 frames is about 0.2 seconds.
Menu Scroll Repeat IntervalMenu repeat intervalOnce repeating, how many frames between moves. Default 5 frames, range 1–20; lower is faster.
Page Up and Page Down BehaviorMenu page turningNo Change keeps the original behaviour; Auto turns a page by the number of visible entries; Fixed uses a set number of entries (1–100). Mainly for item and bank lists.
QUICK MENU MATERIALSMaterials in the shortcut menuAdds materials to the shortcut menu for convenience; it doesn’t change the related limits in challenge or battle quests.
ONE PERSON I-FRAMESSingle-player invincibility timeIn One Person mode, uses a longer post-hit invincibility time like the old offline mode; off uses the original BB behaviour. Only for One Person rooms, not a multiplayer room that happens to have one player.
QUICK MENU UNTEKKED WEAPONSUnidentified weapons in the shortcut menuShows unidentified weapons in the shortcut menu too; it doesn’t identify them for you.
SAVE PARTY INFOSave room infoRemembers the name, password, type and difficulty of rooms you create, and the password used when joining a room of the same name. This was enabled in the 2026-08-01 update; older sources calling it a placeholder switch are out of date.

Further sources: Page turning and single-player update notes; Announcement that Save room info is enabled.

06 / MORE

MORE: original detailed settings

MORE opens the separate option.exe. It manages the original graphics details, fog, sound switches and game font.

Control / meaningWhat it does and notes
PresetGraphics presetHigh end/Normal/Low end adjust several original graphics parameters together; Custom means your own combination. Low end also includes frame skipping, so it isn’t just texture quality.
ColorsColour depth16bit or 32bit, the game’s output colour depth.
Wait V-SyncWait for vertical syncMakes presentation wait for the display’s sync, reducing tearing; actual behaviour also depends on the rendering backend and driver.
Word WrapWord wrapControls automatic line wrapping of text at line ends.
Frame Skip / Auto Frame SkipFrame skip / auto frame skipFrame Skip sets the skip level (0–2, 0 skips nothing on purpose); Auto Frame Skip lets the game skip drawing some frames when it can’t keep up with the target pace.
Advanced EffectOriginal advanced effectsControls the original client’s advanced visual effects, managed separately from Ephinea post-processing switches such as Bloom on page 2.
Low Res TextureLow-resolution texturesLowers texture resolution, trading detail for lower resource use.
Shadow / Enemy / MapShadow / enemy / map detailControls the original detail levels: Shadow 0–2, Enemy 0–1, Map 0–2. The visual difference depends on the scene and resources.
Clip DistanceDraw distanceAdjusts the original scene draw distance. Normal levels are 0–2; higher levels are an extended range, and the program warns of the risk when saving.
Fog EffectFog implementationVertex Fog calculates per vertex; Pixel Fog per pixel; Emulation Fog uses emulation. Compatibility and appearance depend on the graphics backend.
Sound Effects / Background MusicSound effects / music switchesEnable or disable sound effects and background music separately; together with page 1’s volume sliders they decide the final sound.
Global Focus SoundBackground soundKeeps playing sound after the game window loses focus.
FontGame fontChoose a font installed in Windows. Chinese glyph coverage depends on the font; available fonts and rendering can differ between Wine and Windows.
Save ID and PasswordSave login infoControls whether the game saves your login ID and password; see saving your game account.
Hardware LogHardware diagnostic logRuns the DirectX diagnostic tool to create a hardware log for troubleshooting compatibility.
Save / CancelSave / cancelSave writes this window’s settings; Cancel discards this window’s unsaved changes and returns to the launcher.

Version and scope

This page follows version 3.5.2’s interface, the program’s settings read/write logic and official update notes. Screenshots keep Windows’ native look with only the desktop background cropped; under Wine, fonts, control appearance and available backends may differ. Game effects also depend on the client DLL, drivers and graphics backend, and the screenshots don’t mean each effect has been tested in game one by one.

For choosing anti-aliasing or troubleshooting backend compatibility, continue with the rendering and graphics API guide. Control names are kept in English to match the interface.
