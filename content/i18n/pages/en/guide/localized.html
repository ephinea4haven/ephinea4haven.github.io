Step 1: download the Chinese patch

In the QQ group files, open the “Client” folder and download the latest Chinese patch switcher:

File name format:汉化切换器_V{year}.{month}.{day}.{build}.zip

For example:汉化切换器_V2026.03.03.006.zip

Step 2: switch the launcher’s update channel

In the top right of the launcher, switch the update channel to Custom (custom), so official automatic updates don’t overwrite the Chinese files.

Step 3: install the patch

  1. Extract the downloaded archive into the game’s root folder
  2. Run the switcher and follow the prompts
  3. If the system asks about overwriting files, choose Overwrite

Step 4: check it worked

Restart the launcher and enter the game; if the interface shows Chinese, it worked.

Note:After each major official client update you may need to download and install the latest Chinese patch again. Watch for update notices in the QQ group.
