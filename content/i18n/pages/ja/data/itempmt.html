ItemPMT（Item Parameter Table）はPSOのクライアントとサーバーが共有するアイテムパラメータ表です。武器・鎧・盾・ユニット・マグ・消耗品の基本性能、名称の索引、装備条件、説明文、外観モデルを定義します。ItemPTとItemRTは出現条件と確率を扱い、アイテム自体の詳細はItemPMTから取得します。

概要ファイルとバージョン武器鎧・盾ユニットマグ消耗品エクストラアタック表その他のサブテーブルデータ構造

概要

ItemPMTはゲームのアイテム辞書に相当します。アイテムIDから次の情報を取得できます。

  • 表示名（TextEnglish・TextJapanese内の文字列索引）
  • モデルとテクスチャ
  • 分類（武器・鎧・盾・ユニット・マグ・消耗品・テクニック・など）
  • 基本性能（武器のATP・ATA、鎧のDFP・EVP、盾の耐性など）
  • 装備制限（職業フラグ、必要ATP・MST・ATA、必要レベル）
  • 最大付加、レア度、売却可否、基本売価

セーブデータ内のアイテムを読み込むとき、詳細を表示するとき、サーバーが装備条件を判定するときに使用します。

ファイルとバージョン

ItemPMTはPRS圧縮されたバイナリファイルで、PSOの各版に対応する形式があります。

  • ItemPMT-bb-v4.prs— PSOBB公式版・Ephinea
  • ItemPMT-gc-v3.prs— GameCube版（Episode I & II）
  • ItemPMT-gc-ep3.prs— Episode III（カードゲーム）
  • ItemPMT-xb-v3.prs— Xbox版
  • ItemPMT-pc-v2.prs— PC v2版
  • ItemPMT-dc-v1.prs/ItemPMT-dc-v2.prs— Dreamcast v1・v2版
  • NTE（Network Trial Edition）や2000年11月のプロトタイプ版もあります。

武器

武器のフィールドは大きく3つに分かれます。

識別と分類

  • ID：アイテム固有番号で、名称の文字列索引も指定
  • Model / Texture：3Dモデルとテクスチャ
  • Type / Subtype：武器系統とサブタイプ。例えばセイバー系の・・など
  • Class Flags：装備可能職業。HUmar・HUnewearl・HUcastなど12職業に各1ビット

戦闘パラメータ

  • ATP Min / ATP Max：基礎ATP範囲。実際の値は範囲内でランダム
  • ATA：武器のATA加算値
  • Max Grind：最大付加（+9なら9）
  • Photon：フォトン種別。近接・射撃・法撃の分類とコンボ動作を決定
  • Special：既定のエクストラアタックID（参照先：エクストラアタック表）

装備条件

  • ATP Required：装備に必要な最低ATP
  • MST Required：装備に必要な最低MST
  • ATA Required：装備に必要な最低ATA

鎧（Armor / Frame）と盾（Shield / Barrier）

鎧と盾は共通の構造を使い、別々のサブテーブルに格納します。各エントリは次を含みます。

  • DFP / EVP：基礎防御力と回避力。武器と同様にmin–maxの範囲内で変動
  • Class Flags：装備可能職業
  • 必要レベル：装備できる最低レベル
  • DFP・EVP補正上限：鎧の強化による加算上限（鎧の+N）
  • ユニットスロット：盾は常に0、鎧は0～4。レア鎧のスロット数も固定ではなくItemPTで決定
  • 5属性耐性：EFR・EIC・ETH・EDK・ELT（炎・氷・雷・闇・光）

ユニット

ユニットのエントリは比較的単純です。

  • Class Flags：装備可能職業
  • Stat Bonus：加算する能力と数値（HP・TP・ATP・DFP・ATA・EVP・LCK・MSTなど）
  • プラス・マイナスのしきい値：/表記のユニット（例：、HP/Resurrect）の発動率またはクールダウン
  • レア度：コモンかレアかを決定

一部のユニットは数値加算ではなく個別の効果判定で動作します。例：、/、。ItemPMTに効果の数値を持たず、ゲームコードがIDを識別して専用効果を発動します。

マグ

マグのパラメータはItemPMTの中でも特徴的です。各マグのエントリは次を含みます。

  • Model ID：進化後の外観。DEF・POW・DEX・MINDと持ち主の職業系統に依存
  • フォトンポイントのコスト（餌テーブル）：各アイテムを与えたときの能力変化と変化量
  • フォトンブラストの組み合わせ：3つの枠に設定できるPB

マグの餌テーブルはItemPMT内の大きな表で、8つの餌テーブル×11種の餌で構成され、マグの種類ごとにいずれか1つのテーブルを参照します。各マスがDEF・POW・DEX・MIND・SYNC・IQの変化を指定します。

消耗品（Tools）

道具のエントリは最も単純で、主に次を含みます。

  • IDと名称索引
  • 使用効果ID。回復・状態異常解除・転送などの処理はゲームコードがIDごとに実行
  • 所持上限（Stack Max）：1枠の最大数。回復アイテムやは10個、は99個など。
  • 売却可否/基本売価
  • レア度：例えばは消耗品ですがレア度を持ちます

テクニックディスクも道具分類ですが、構造はテクニックIDとレベルの組で、所持上限は1固定です。

エクストラアタック表

チャージ・スピリット・バーサーク・ガイスト・ヘル・デーモン・アレスト・カオス・ブリザード・バーニングなどは独立した表に格納され、ItemPMTからIDで参照されます。各エントリは次を含みます。

  • 名称索引（チャージ、バーサークなど）
  • レア度：コモン武器の生成でレア度を抽選し、そのランクの能力を選択
  • 発動パラメータ：成功率、消費（MST・HPなど）、追加ダメージ

コモン武器のエクストラアタックはどう決まるか
武器のSpecial欄を直接読むのではなく、ItemPTがエリアに応じて0～5のランクを生成し、ItemPMTの対応する能力から選択します。たとえば坑道で拾った武器には1★のDraw、遺跡で拾った同じ武器には4★のGushが付くことがあります。エリアによって候補が異なります。

その他のサブテーブル

主要なアイテム以外にも、各種処理で参照する補助テーブルがあります。

合成・強化（Item Combination Table）

レシピには使用アイテム×装備中の対象×生成結果と、追加条件を格納します。

  • 必要マグレベル、武器付加、キャラクターレベル、職業
  • 例：からへの合成や、専用道具による武器の強化

この表はコンボ表とは別物です。N-N-H・N-H-Hなどのコンボ補正はクライアントに固定実装されています。ItemPMTでコンボに関係するのは、武器ごとの1バイトのbehavior_flagsのみで、コンボ禁止のビットを含みます（一部の武器は連続攻撃できません）。

Tech Boost Table

杖などによるテクニックのダメージ・範囲補正。例として、はラフォイエ・ラバータ・ラゾンデのダメージ+30%、はジェルン・ザルアの範囲+100%です。武器のtech_boostフィールドから参照します。

Special Data / Weapon Effect / Shield Effect

  • Special Data Table：チャージ・バーサーク・ヘル・デーモンなど、前述の能力パラメータ。
  • Weapon Effect Table：HP吸収や耐性など、装備中の武器のパッシブ効果。
  • Shield Effect Table：自動回復や一部レア盾の追加効果など、盾のパッシブ効果。
  • Ranged Special Table：射撃武器のエクストラアタック動作。射撃武器では挙動が変わる能力があります。

Stat Boost Table

ユニットが参照する加算データです。ユニット本体はboost IDを保持し、ここから能力の種類と値を取得します。

Max Tech Level Table

職業ごとのテクニック習得上限です。例としてフォースはLv30ラフォイエ、ハンターはLv15までと説明されています。上限を超えるディスクは使用できません。

Photon Color / Weapon Range / Star Value

  • Photon Color Table：フォトンの刃の色。種別ごとにRGBの組を持ちます。
  • Weapon Range Table：武器の攻撃距離と判定範囲。
  • Star Value Table：IDからレア度への対応表。名称の横に表示する☆の数を決定します。

Unsealable / Unwrap

  • Unsealable Table：、などの封印解除後の武器。
  • Unwrap Table：やなどを開いた際の候補。

Sale Divisor / V1 Replacement

  • Weapon Sale Divisor / Non-Weapon Sale Divisor：店の売価計算に使うアイテムごとの除数。
  • V1 Replacement Table：PSO v1のIDをBBの対応アイテムに置き換えます。
