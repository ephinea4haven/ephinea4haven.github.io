Windows の DEP を設定する

1. デスクトップの PC のアイコンを右クリックし、 プロパティ。

2. 開いた システム のウィンドウで システムの詳細設定。

3. システムのプロパティ → 詳細設定 → パフォーマンス の欄で 設定。

4. パフォーマンス オプション で データ実行防止 タブに切り替えます。

ここでプロセッサーが DEP に対応しているか確認できます：

  • 対応していれば次のように表示されます：このコンピューターのプロセッサは、ハードウェアベースの DEP をサポートしています。
  • 対応していなければ次のように表示されます：このコンピューターのプロセッサは、ハードウェアベースの DEP をサポートしていません。ただし、Windows は DEP ソフトウェアを使用して、一部の種類の攻撃を防ぐことができます。

互換性を設定する

1. ゲームのショートカットを右クリックし、 プロパティ。

2. 互換性 タブに切り替えます。

3. Run this program in compatibility mode for:

4. Windows XP (Service Pack 2)。

ランチャーの解像度を設定する

最初の2つの手順の後もまだ落ちる場合は、 解像度。

グラフィックカードとモニターに合った解像度を選んでください：

> 高い解像度が必ず重いわけでも、低い解像度が必ず軽いわけでもありません。実際の様子で判断してください。

ユーザーアカウント制御（UAC）を設定する

UAC を下の図の段階に設定すると、ほかのプログラムが保護の確認画面を出したときに

PSOBB が描画を失って落ちることがなくなります。

ゲームのフォルダーをウイルス対策ソフトの除外に追加する

ゲームの左下に DLL ERROR などと表示される場合は、次の手順に従ってください：

1. スタートメニューで sec と入力し、

2. ウイルスと脅威の防止

3. 設定の管理

4. 除外の追加または削除

5. ゲームのルートフォルダー を除外に追加します

これでゲームのフォルダーの除外の設定は完了です。
