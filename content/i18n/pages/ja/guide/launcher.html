操作方法：OPTIONS で設定を開き、NEXT PAGE／PREVIOUS PAGE でページを切り替えます。緑のスイッチはオン、灰色はオフです。灰色でもクリックできないとは限りません。画像はこのパソコンのその時点の設定で、おすすめの値ではありません。画像をクリックすると元のサイズで見られます。

メイン画面と保存のしかた

コントロール働き
START GAMEゲームを起動します。アカウントのログインとキャラクターの選択はゲーム内で行います。
ENGLISH / 日本語 / CUSTOM言語リソースの更新のしかたを選びます。CUSTOM はカスタムのリソース用で、中国語の選択肢が内蔵されているわけではありません。画像の CUSTOM と英語の画面は同時に使えます。言語を切り替えると今の設定が保存され、更新の確認が行われるので、独自の翻訳を管理している場合は選んだリソースのモードを確認してください。
OFFICIAL SITE / REGISTER / FAQ / DONATE公式サイト、アカウント登録、よくある質問、寄付のページをそれぞれ開きます。
CREDITS / QUITスタッフ一覧を表示／ランチャーを終了します。
CHECK FOR UPDATESクライアントの更新を再確認します。設定を元に戻すものではありません。
MORE先にランチャーの設定を保存してから、独立したオリジナルの詳細設定ウィンドウを開きます。
REVERT保存済みの設定を読み直し、まだ保存していない変更を取り消します。
RESET ALL今の多くの設定をプログラムが決めた初期値に戻します（この時点ではまだ保存されません）。言語の選択も English に、解像度も 1024×768 に戻ります。CUSTOM のリソースが必要なら、この後の保存や更新の前に言語の選択を確認してください。3.5.2 のリセットは後から追加された項目をすべては対象にしていないため、すべての設定を完全に消すものではありません。

どうやって保存する？ランチャーには共通の Save ボタンがありません。START GAME・QUIT・MORE などの操作で設定が書き込まれ、OPTIONS をもう一度押してもパネルが閉じるだけです。変更を取り消したいときは、先に REVERT を使ってから保存される操作をしてください。MORE のウィンドウには専用の Save／Cancel があります。

01 / OPTIONS

画面・サウンド・インターフェース

まずゲームのウィンドウと描画方法を決め、次にインターフェースの大きさとサウンドを調整します。

英語のコントロール / 意味働きと注意点
Resolution解像度ゲーム画面の幅・高さ・縦横比を決めます。Custom で幅と高さを自由に入力できます。高い解像度はたいてい鮮明になりますが、描画の負荷も増えます。
Windowed ModeウィンドウのモードFullscreen は排他的なフルスクリーン、Windowed は普通のウィンドウ、Virtual Fullscreen は枠のないフルスクリーンです。アプリを切り替えるときは、普通のウィンドウか枠のないフルスクリーンのほうが便利です。
Rain/Laser Scale雨・レーザーの線の拡大率雨やレーザーなど線状のエフェクトの表示倍率を調整します。100% が基準で、攻撃のダメージや判定の範囲は変わりません。
Direct3D API描画のバックエンドD3D8、D3D9、D3D9on12、dgVoodoo 経由の D3D11／12、DXVK 経由の Vulkan から選びます。括弧内は変換コンポーネントのバージョンで、Custom は自分で用意したコンポーネントを使います。互換性はドライバーと実行環境によって変わります。詳しくは描画 API のガイド。
Anti-AliasingアンチエイリアスNone でオフ。MSAA は形状の輪郭を処理し、SSAA は内部の描画解像度を上げてから縮小し、SMAA は画像の輪郭を後処理し、HSAA は SSAA と MSAA を組み合わせます。+ SMAA の付いた項目は SMAA を追加します。高い設定ほど負荷はたいてい増えます。バックエンドごとの対応はアンチエイリアスの説明。
Anisotropic Filtering異方性フィルタリングDisabled か 2×／4×／8×／16×。斜めに見える床や道などの表面のテクスチャを鮮明にします。
BGM / SFXBGM／効果音の音量BGM と効果音を別々に 0～10 で調整します。0 で無音です。
DISABLE SKIN SFX外観専用の効果音をオフ武器の外観（スキン）専用の効果音をオフにします。ゲームのすべての効果音をオフにするものではありません。
HIGH RES HUD / HUD Scale高解像度 HUD／インターフェースの倍率高解像度 HUD を有効にすると HUD Scale が表示されます。値が大きいほど HUD は画面上で小さくなり、使える空間が増えます。高解像度のインターフェースのテクスチャを入れるものではありません。
Damage Scaleダメージの数字の倍率ダメージの数字の表示の大きさだけを変え、実際のダメージは変わりません。
NO MINIMAP SCALEミニマップの倍率補正をオフ高解像度 HUD のミニマップの倍率補正をオフにします。この補正は、HUD の解像度が違っても同じ内部の視野範囲を表示し、アイコンの比率を調整するもので、ミニマップの枠全体の大きさを固定するものではありません。未探索の場所が見えるようにはなりません。参照：元の拡大縮小の説明とオプションのお知らせ。
IME入力メソッドへの対応中国語・日本語などの文字入力のため、クライアントの入力メソッド（IME）対応を有効にします。使える入力メソッドは実行環境によります。
LOW PERFORMANCE低負荷での実行クライアントのメインループが CPU の時間をより積極的に譲るようにし、CPU の使用率を下げます。フレームのテンポに影響することがあります。通信の高速化でも、画質をまとめて下げるボタンでもありません。
CLASSIC INTRO FMV旧式のオープニングムービーの再生方法オンにすると、キャラクター作成のオープニングに旧式の PAE ムービーと元のプレイヤーを使います。オフでは新しいムービーの再生方法を使います。ムービーを飛ばすものではありません。参照：2つの再生方法についての公式の説明。

補足の出典：Low Performance についてのスタッフの説明；HUD Scale と高解像度のインターフェースのテクスチャの違い。

便利機能と画面効果

このページには倉庫の操作の項目と、後処理や dgVoodoo の設定があります。

英語のコントロール / 意味働きと注意点
FAST STARTUPクイックスタートSEGA、Sonic Team などのロゴの画面を飛ばします。ランチャーの更新の確認は飛ばしません。
CLEAN CAPTUREきれいなスクリーンショットゲーム内蔵のスクリーンショットの取り方を変え、ゲームの画面のバッファから取り込んで、アドオンの重ね表示が写らないようにします。ゲームの HUD は自動では隠れません。
MOTION BLURモーションブラーゲーム本来の残像の効果を切り替えます。
RARE DROP SFXレアドロップの通知音レアアイテムがドロップしたときに音を鳴らします。ドロップ率は変わりません。
BANK SHORTCUTS倉庫の数字キー倉庫の一覧で数字キー 1～0 を使ってすばやく移動します。キャラクターの倉庫を切り替えるコマンドではありません。
LARGE BANK WINDOW大きな倉庫のウィンドウ倉庫の一覧を広げ、一度に多くの項目を表示します。
BLOOMブルーム明るい部分の周りに光のにじみを加えます。
DEPTH OF FIELD被写界深度奥行きに応じて画面の一部をぼかし、手前と奥の見え方の鮮明さを変えます。
CEL SHADINGセルシェーディング輪郭を強め、アニメ風の画面にします。
TONEMAPPINGトーンマッピング画面の明るさ・コントラスト・色合いの表現を調整します。
Ambient OcclusionアンビエントオクルージョンDisabled／Low／Medium／High。物の接する所や遮られた部分に陰影を加えます。後処理の効果と負荷はシェーダーの説明。
dgVoodoo Model表示の方式Auto、Discard、Sequential、Flip Discard、Flip Sequential はスワップチェーン／表示の方式で、画質の段階ではありません。dgVoodoo を使うときだけ意味があります。詳しくはスワップチェーンの説明。
dgVoodoo VRAM仮想ビデオメモリAuto か 64～4096 MB。dgVoodoo が古いゲームに見せるビデオメモリの量を設定します。グラフィックカードの物理メモリが増えるわけではありません。

補足の出典：クイックスタートの更新情報；Clean Capture の更新情報。

03 / OPTIONS

通知・カメラ・文字

カメラの操作は、自分のゲームパッドと操作の癖に合わせて設定できます。一部のコントロールは関連する機能を有効にしたときだけ表示されます。

英語のコントロール / 意味働きと注意点
SDJZ Icon補助の状態アイコンシフタ・デバンド・ジェルン・ザルアのアイコンの表示方法を切り替えます：Normal（通常）、Blink（点滅）、Fade（徐々に消える）。
Mag Alertマグのエサやりの通知オンにすると、連れているマグにエサを与えられるようになったとき音を鳴らします。
Mag Alert Delay通知の間隔2回の通知音の最短の間隔で、単位は秒、初期値は 30 です。マグのエサやりの待ち時間ではありません。
Analog Camera Controlスティックでのカメラ操作ゲームパッドの右スティックでカメラを動かせるようにします。
Analog Sensitivity / INVERTカメラの感度／反転感度はスティックでカメラが回る速さで、INVERT は対応するカメラの方向を反転します。
Camera Dead Zoneカメラのスティックのデッドゾーンスティックの中心付近の小さな入力を無視し、カメラが勝手に動くのを防ぎます。大きすぎると操作できる範囲が狭くなります。
ANALOG CAMERA KEYS / TURN LEFT / TURN RIGHTキーボードでのカメラ操作カメラを左右に回すキーボードのキーを有効にして指定します。関連するコントロールはカメラの項目と一緒に表示されます。
Chase Camカメラの自動追従Enabled は自動で追従、Disabled は自動追従をやめ、手動のカメラか正面に戻すキーを使います。Hybrid はスティックでカメラを操作している間だけ自動追従を止め、Toggle はスティックで操作した後は手動のままで、正面に戻すキーで追従に戻ります。
Font Render Method文字の描画方法Hi-Res (Antialiased) はアンチエイリアスの高解像度の字形、Hi-Res (ClearType) は ClearType、Normal は通常の方式を使います。フォント自体は MORE で選びます。
Font Resolution字形の解像度Auto か、字形をラスタライズする解像度を指定します。鮮明さとサンプリングに影響し、すべての文字をその数値の大きさにするのとは違います。
NUMPAD SHORTCUTSテンキーのショートカットテンキーで対応する数字のショートカットを使えるようにします。
Show Mob Drop狙った敵のレアドロップの表示Disabled でオフ、Drop Only はアイテムだけ、Drop (Current Rate) は現在の確率も、Drop (Current & Base Rate) は現在と基本の確率の両方を表示します。対象の情報の欄に表示され、確率はクライアントが計算するので丸めの差があることがあり、次のドロップの予測ではありません。
ENHANCED MAP DRAW描画範囲の拡張より多くの背景の形状を描画できるようにし、本来の描画距離やカリングによる欠けを減らします。負荷が増えることがあります。ミニマップの探索や敵の出現とは関係ありません。

補足の出典：カメラのモード、マグの通知、フォントの更新情報；描画範囲と狙った敵のドロップ表示の説明。

04 / OPTIONS

ゲームパッド・拾う操作・フォトンブラスト

誤って押しやすい拾う操作とフォトンブラストを、修飾キーを押している間だけ使える操作に移します。

英語のコントロール / 意味働きと注意点
AUTO DETECT ACTIVE GAMEPAD今のゲームパッドを自動認識最後に使ったゲームパッドを自動で使い、複数のコントローラーを切り替えるときに便利です。
USE XINPUT FOR GAMEPADXInput を使うXInput のゲームパッドのインターフェースに切り替え、対応するコントローラーの抜き差しやトリガーボタンに対応します。オンにすると下の3つの調整項目が表示されます。XInput 以外の機器はマッピングが必要なことがあります。
Deadzoneスティックのデッドゾーンスティックの中心付近の小さな入力を除きます。範囲は 0～75%。
Axis Snapping方向の吸着水平や垂直に近い入力を、まっすぐの方向に入りやすくします。範囲は 0～50%。
Trigger Thresholdトリガーのしきい値トリガーをどこまで押したら入力とみなすか。範囲は 0～100%。
Item Pickup and Photon Blast Usage拾う操作／フォトンブラストの操作方法Disabled は元の操作のままで、近くのアイテムでメインのアクションバーの中央が拾う操作に替わったり、フォトンブラストがたまるとサブのアクションバーを占めたりします。ほかの3つは、修飾キーを押している間だけ拾う操作、フォトンブラスト、またはその両方を使えるようにし、離すと元のアクションバーに戻ります。
HOLD GAMEPAD BUTTONゲームパッドの修飾キーゲームパッドのボタンで上の操作を使えるようにします。ゲーム内の Options → Pad button config の一番下の項目でボタンを割り当てます。
HOLD SHIFT KEY / HOLD ALT KEY / HOLD KEYキーボードの修飾キーShift、Alt、または指定したキーを選びます。関連するコントロールは、拾う操作／フォトンブラストの制限を有効にすると表示されます。これらの項目で自動的に拾ったり、フォトンブラストを撃ったりはしません。

05 / OPTIONS

メニュー操作とゲームの便利設定

メニューの反応の速さ、ショートカットメニューの中身、実際にソロの戦闘に影響する項目を区別します。

英語のコントロール / 意味働きと注意点
Menu Scroll Repeat Delayメニューの連続移動の開始の遅れ方向を押し続けてから連続移動が始まるまでに待つフレーム数。初期値 6 フレーム、範囲 1～20 フレームで、30 FPS なら 6 フレームは約 0.2 秒です。
Menu Scroll Repeat Intervalメニューの連続移動の間隔連続移動が始まった後、何フレームごとに1回動くか。初期値 5 フレーム、範囲 1～20 フレームで、小さいほど速く動きます。
Page Up and Page Down Behaviorメニューのページ送りNo Change は元の動作のまま、Auto は今見えている項目数ずつ、Fixed は指定した項目数（1～100）ずつページを送ります。主にアイテムや倉庫などの一覧に使います。
QUICK MENU MATERIALSショートカットメニューにマテリアルを表示マテリアルをショートカットメニューに加えて使いやすくします。チャレンジやバトルのクエストでの制限は変わりません。
ONE PERSON I-FRAMESソロモードの被弾後の無敵時間One Person モードで、昔のオフラインモードのような長めの被弾後の無敵時間を使います。オフにすると本来の BB の動作です。部屋の種類が One Person のときだけで、マルチプレイの部屋に1人しかいない場合は対象外です。
QUICK MENU UNTEKKED WEAPONSショートカットメニューに未鑑定の武器を表示未鑑定の武器もショートカットメニューに表示します。鑑定はしてくれません。
SAVE PARTY INFO部屋の情報を保存作成した部屋の名前・パスワード・種類・難易度と、同じ名前の部屋に入るときのパスワードを覚えておきます。この機能は 2026-08-01 の更新で有効になり、以前の資料にある「中身のないスイッチ」という説明は古くなっています。

補足の出典：ページ送りとソロモードの更新情報；部屋の情報の保存が有効になったお知らせ。

06 / MORE

MORE：オリジナルの詳細設定

MORE は独立した option.exe を開きます。ここではオリジナルのグラフィックの詳細、フォグ、サウンドのスイッチ、ゲームのフォントを管理します。

英語のコントロール / 意味働きと注意点
PresetグラフィックのプリセットHigh end／Normal／Low end はオリジナルのグラフィックのいくつかの設定をまとめて変え、Custom は自分で組み合わせることを表します。Low end にはフレームスキップの設定も含まれるので、テクスチャの品質だけの話ではありません。
Colors色深度16bit か 32bit。ゲームの出力の色深度を選びます。
Wait V-Sync垂直同期を待つ画面の表示がディスプレイの同期を待つようにし、ティアリングを減らします。実際の動作は選んだバックエンドとドライバーにも左右されます。
Word Wrap自動改行行末での文字の自動改行を切り替えます。
Frame Skip / Auto Frame Skipフレームスキップ／自動フレームスキップFrame Skip はスキップの段階を設定し（0～2、0 は意図的にスキップしない）、Auto Frame Skip は目標のテンポに追いつけないときに一部の描画を自動で飛ばします。
Advanced Effectオリジナルの高度な効果オリジナルのクライアントの高度な画面効果を切り替えます。2ページ目の Bloom などの Ephinea の後処理とは別に管理されます。
Low Res Texture低解像度のテクスチャテクスチャの解像度を下げ、細部と引き換えに使うリソースを減らします。
Shadow / Enemy / Map影／敵／マップの詳細度オリジナルの詳細度を切り替えます：Shadow 0～2、Enemy 0～1、Map 0～2。見た目の違いは場面とリソースによります。
Clip Distance描画距離オリジナルの背景の描画距離を調整します。通常の段階は 0～2 で、それ以上は拡張の範囲になり、保存するとプログラムが危険を警告します。
Fog Effectフォグの方式Vertex Fog は頂点ごと、Pixel Fog はピクセルごとに計算し、Emulation Fog はエミュレーションを使います。互換性と見た目は描画のバックエンドによります。
Sound Effects / Background Music効果音／BGM のスイッチ効果音と BGM を別々にオン・オフします。1ページ目の音量のスライダーとあわせて最終的な音が決まります。
Global Focus Soundバックグラウンドのサウンドゲームのウィンドウが選ばれていなくても音を鳴らし続けます。
FontゲームのフォントWindows に入っているフォントから選びます。中国語の字形にどこまで対応するかはフォント次第で、使えるフォントと表示は Wine と Windows で違うことがあります。
Save ID and Passwordログイン情報の保存ゲームがログイン ID とパスワードを保存するかを切り替えます。詳しくはゲームのアカウントの保存。
Hardware Logハードウェアの診断ログDirectX の診断ツールでハードウェアの情報のログを作り、互換性の問題を調べるのに使います。
Save / Cancel保存／キャンセルSave でこのウィンドウの設定を書き込み、Cancel はこのウィンドウの保存していない変更を捨ててランチャーに戻ります。

バージョンと適用範囲

このページは 3.5.2 の画面、プログラムの設定の読み書きの処理、公式の更新情報に基づいています。画像は Windows 本来の表示のまま、デスクトップの背景だけを切り取っています。Wine ではフォント、コントロールの見た目、使えるバックエンドが違うことがあります。ゲームの効果はクライアントの DLL、ドライバー、描画のバックエンドにも左右され、画像は各効果をゲーム内で1つずつ試したことを意味しません。

アンチエイリアスの選び方やバックエンドの互換性の確認は、続けて描画とグラフィック API のガイドを読んでください。コントロール名は画面と照らし合わせやすいよう英語のままにしています。
