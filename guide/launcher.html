先看操作方法：点击 OPTIONS 打开设置，用 NEXT PAGE／PREVIOUS PAGE 翻页。绿色开关表示开启，灰色表示关闭；灰色不一定表示无法点击。截图展示的是这台电脑当时的配置，不是统一推荐值。点击图片可查看原图。

主界面与保存方式

控件作用
START GAME启动游戏；账号登录和角色选择在游戏内进行。
ENGLISH / 日本語 / CUSTOM选择对应的语言资源更新方式。CUSTOM 用于自定义资源，不是内置的“中文”选项；截图中的 CUSTOM 与英文界面可以同时存在。切换语言会保存当前设置并触发更新检查，维护自定义汉化时需确认所选资源模式。
OFFICIAL SITE / REGISTER / FAQ / DONATE分别打开官方网站、账号注册、常见问题和捐赠入口。
CREDITS / QUIT查看制作名单／退出登录器。
CHECK FOR UPDATES重新检查客户端更新，不等于恢复设置。
MORE先保存登录器设置，再打开独立的原版详细设置窗口。
REVERT重新读取已保存的配置，撤回尚未保存的修改。
RESET ALL把多项当前设置重置为程序指定的初始值，此时尚未保存；也会把语言选择重置为 English、分辨率重置为 1024×768。需要 CUSTOM 资源时，在执行后续保存或更新操作前确认语言选择。3.5.2 的重置逻辑未覆盖全部后加选项，不能当成完整清除所有配置。

怎样保存？登录器没有统一的 Save 按钮。START GAME、QUIT、MORE 等操作会写入设置；再次点击 OPTIONS 只收起面板。希望撤回修改时，应先使用 REVERT，再执行会保存的操作。MORE 窗口有自己的 Save／Cancel。

01 / OPTIONS

画面、声音与界面

先决定游戏窗口与渲染方式，再调整界面大小和声音。

英文控件 / 中文含义作用与注意点
Resolution分辨率决定游戏画面的宽、高及宽高比。Custom 可输入自定义宽高；高分辨率通常更清晰，也增加绘制开销。
Windowed Mode窗口模式Fullscreen 为独占全屏；Windowed 为普通窗口；Virtual Fullscreen 为无边框全屏。切换应用时，普通窗口或无边框全屏通常更方便。
Rain/Laser Scale雨线／激光缩放调整雨线、激光等线状特效的显示比例，100% 为基准；不改变攻击伤害或判定范围。
Direct3D API渲染后端选择 D3D8、D3D9、D3D9on12，或经 dgVoodoo 输出的 D3D11／12、经 DXVK 输出的 Vulkan。括号里的版本是转换组件版本，Custom 使用自行提供的组件。兼容性取决于驱动与运行环境，详见图形后端指南。
Anti-Aliasing抗锯齿None 关闭；MSAA 处理几何边缘；SSAA 提高内部渲染分辨率后缩小；SMAA 对图像边缘做后处理；HSAA 组合 SSAA 与 MSAA。带 + SMAA 的选项追加 SMAA。更高档位通常增加负载，各后端支持情况见抗锯齿说明。
Anisotropic Filtering各向异性过滤Disabled 或 2×／4×／8×／16×。改善斜视地板、道路等表面的纹理清晰度。
BGM / SFX音乐／音效音量分别调节背景音乐和音效，范围 0–10；0 为静音。
DISABLE SKIN SFX关闭外观专用音效关闭武器外观（skin）的专用音效，不是关闭游戏全部音效。
HIGH RES HUD / HUD Scale高分辨率 HUD／界面缩放启用高分辨率 HUD 后显示 HUD Scale。数值越大，HUD 在屏幕上越小、可用空间越多；这项不会自动安装高清界面贴图。
Damage Scale伤害数字缩放只调整伤害数字的显示大小，不改变实际伤害。
NO MINIMAP SCALE关闭小地图缩放修正关闭高分辨率 HUD 的小地图缩放修正。原修正用于让不同 HUD 分辨率显示相同的内部视野范围，并调整图标比例；不是固定整个 HUD 小地图框的大小。不会揭示未探索区域。参见原缩放行为说明与关闭选项公告。
IME输入法支持启用客户端的输入法支持，供中文、日文等文字输入使用；可用输入法由运行环境提供。
LOW PERFORMANCE低负载运行让客户端主循环更主动地让出 CPU 时间，降低 CPU 占用；可能影响帧节奏。不是网络加速，也不是一键降低全部画质。
CLASSIC INTRO FMV旧版开场影片播放方式开启时，创建角色的开场使用旧版 PAE 影片及原播放器；关闭时使用新版影片播放路径，不代表跳过影片。参见官方对两种播放方式的说明。

补充依据：官方人员对 Low Performance 的说明；HUD Scale 与高清界面贴图的区别。

02 / OPTIONS

便利功能与画面效果

这页既有仓库操作选项，也有后处理和 dgVoodoo 设置。

英文控件 / 中文含义作用与注意点
FAST STARTUP快速启动跳过 SEGA、Sonic Team 等启动标志画面，不会跳过登录器更新检查。
CLEAN CAPTURE干净截图改变游戏内置截图的取图方式，从游戏画面缓冲区取图，避免把附加组件叠加层一起截入。不会自动隐藏游戏 HUD。
MOTION BLUR动态模糊控制游戏原有的动态拖影效果。
RARE DROP SFX稀有掉落提示音稀有物品掉落时播放提示音；不会改变掉率。
BANK SHORTCUTS仓库数字快捷键在仓库列表中使用数字键 1–0 快速跳转，不是切换角色仓库的命令。
LARGE BANK WINDOW大仓库窗口扩大仓库列表，一次显示更多条目。
BLOOM泛光在明亮区域周围加入光晕。
DEPTH OF FIELD景深根据深度模糊部分画面，改变远近景的清晰程度。
CEL SHADING卡通描边加强轮廓，产生卡通式画面风格。
TONEMAPPING色调映射调整画面的亮度、对比与色调呈现。
Ambient Occlusion环境光遮蔽Disabled／Low／Medium／High；为接触处和遮蔽区域加入暗部层次。后处理效果及负载见着色器说明。
dgVoodoo Model画面呈现模式Auto、Discard、Sequential、Flip Discard、Flip Sequential 是交换链／呈现方式，不是画质等级。仅对 dgVoodoo 路径有意义，详见交换链说明。
dgVoodoo VRAM虚拟显存Auto 或 64–4096 MB，配置 dgVoodoo 向旧游戏呈现的显存容量；不会增加显卡的物理显存。

补充依据：快速启动更新说明；Clean Capture 更新说明。

03 / OPTIONS

提醒、镜头与文字

镜头控制可以按自己的手柄和操作习惯设置。部分控件只在相关功能开启后出现。

英文控件 / 中文含义作用与注意点
SDJZ Icon辅助状态图标控制 Shifta、Deband、Jellen、Zalure 图标的显示方式：Normal 普通、Blink 闪烁、Fade 渐隐。
Mag Alert玛古喂养提醒开启后，当随身携带的玛古可以喂养时播放提示音。
Mag Alert Delay提醒间隔两次提醒音之间的最短间隔，单位为秒，默认 30。它不是玛古的喂养冷却时间。
Analog Camera Control摇杆镜头控制允许用手柄右摇杆调整镜头。
Analog Sensitivity / INVERT镜头灵敏度／反向灵敏度影响摇杆转动镜头的速度；INVERT 反转对应的镜头控制方向。
Camera Dead Zone镜头摇杆死区忽略摇杆中心附近的小幅输入，用于避免镜头漂移；过大会减少有效操控范围。
ANALOG CAMERA KEYS / TURN LEFT / TURN RIGHT键盘镜头控制启用并指定向左、向右旋转镜头的键盘按键；相关控件随镜头选项显示。
Chase Cam自动跟随镜头Enabled 自动跟随；Disabled 关闭自动跟随，使用手动镜头或回正键；Hybrid 在摇杆操作镜头时暂停自动跟随；Toggle 用摇杆操作后保持手动，按镜头回正键恢复跟随。
Font Render Method文字渲染方式Hi-Res (Antialiased) 使用抗锯齿高分辨率字形；Hi-Res (ClearType) 使用 ClearType；Normal 使用普通方式。字体本身在 MORE 中选择。
Font Resolution字形分辨率Auto 或指定字形栅格化分辨率。影响清晰度与采样，不等于把所有文字直接改成同数值的字号。
NUMPAD SHORTCUTS数字小键盘快捷栏允许数字小键盘触发对应的数字快捷栏。
Show Mob Drop目标怪物稀有掉落显示Disabled 关闭；Drop Only 只显示物品；Drop (Current Rate) 加当前掉率；Drop (Current & Base Rate) 同时显示当前与基础掉率。显示在目标信息区域，概率由客户端计算，可能存在舍入差异，不是下一次掉落预测。
ENHANCED MAP DRAW扩展场景绘制让更多场景几何保持可绘制，减轻原有绘制距离与裁切造成的缺失；可能增加负载。与小地图探索或怪物刷新无关。

补充依据：镜头模式、玛古提醒与字体更新说明；场景绘制与目标掉落显示说明。

04 / OPTIONS

手柄、拾取与光子爆发

把容易误触的拾取和光子爆发动作放到需要按住修饰键才能使用的操作层。

英文控件 / 中文含义作用与注意点
AUTO DETECT ACTIVE GAMEPAD自动识别当前手柄自动采用最近使用的手柄，方便连接多个控制器时切换。
USE XINPUT FOR GAMEPAD使用 XInput改用 XInput 手柄接口，支持相应控制器的热插拔及扳机按钮。开启后显示以下三个调整项；非 XInput 设备可能需要映射才能使用。
Deadzone摇杆死区过滤摇杆中心附近的小幅输入，范围 0–75%。
Axis Snapping方向吸附让接近水平或垂直方向的输入更容易落在正方向，范围 0–50%。
Trigger Threshold扳机阈值扳机按下到这个程度才视为触发，范围 0–100%。
Item Pickup and Photon Blast Usage拾取／光子爆发操作方式Disabled 保留原版操作：附近物品可能把主动作栏中间位置换成拾取，光子爆发蓄满时会占用副动作栏。其余三项分别要求按住修饰键才能使用拾取、光子爆发，或二者；释放后保留原动作栏。
HOLD GAMEPAD BUTTON手柄修饰键允许手柄按键触发上述操作层；在游戏内 Options → Pad button config 底部的对应项目绑定按键。
HOLD SHIFT KEY / HOLD ALT KEY / HOLD KEY键盘修饰键选择允许触发的 Shift、Alt 或指定键。相关控件在启用拾取／光子爆发限制后出现。这些选项不会自动拾取，也不会自动释放光子爆发。

05 / OPTIONS

菜单操作与游戏便利设置

区分菜单反应速度、快捷菜单的内容和真正影响单人模式战斗的选项。

英文控件 / 中文含义作用与注意点
Menu Scroll Repeat Delay菜单连移启动延迟按住方向后，等待多少帧才开始连续移动。默认 6 帧，范围 1–20 帧；按 30 FPS 计算，6 帧约 0.2 秒。
Menu Scroll Repeat Interval菜单连移间隔开始连续移动后，每隔多少帧再移动一次。默认 5 帧，范围 1–20 帧；值越小，连移越快。
Page Up and Page Down Behavior菜单翻页方式No Change 保留原行为；Auto 按当前可见条目数翻一页；Fixed 使用指定条目数（1–100）。主要用于物品、仓库等列表。
QUICK MENU MATERIALS快捷菜单显示能力药把能力药加入快捷菜单，便于使用；不改变挑战／对战任务中的相关限制。
ONE PERSON I-FRAMES单人模式受击无敌时间在 One Person 模式采用类似旧版离线模式的较长受击无敌时间；关闭则使用原版 BB 行为。仅限房间类型为 One Person，不是多人房间里只有一个人就生效。
QUICK MENU UNTEKKED WEAPONS快捷菜单显示未鉴定武器让未鉴定武器也出现在快捷菜单中；不会替你鉴定武器。
SAVE PARTY INFO保存房间信息记住创建房间的名称、密码、类型、难度，以及加入同名房间时用到的密码。此功能已于 2026-08-01 更新启用，早期资料中“只是占位开关”的说法已经过时。

补充依据：翻页与单人模式更新说明；保存房间信息正式启用公告。

06 / MORE

MORE：原版详细设置

MORE 会打开独立的 option.exe。这里管理原版图形细节、雾效、声音开关和游戏字体。

英文控件 / 中文含义作用与注意点
Preset图形预设High end／Normal／Low end 会一起调整多项原版图形参数；Custom 表示自行组合。Low end 还包含跳帧设置，不能只把它理解为纹理质量。
Colors颜色深度16bit 或 32bit，选择游戏输出颜色深度。
Wait V-Sync等待垂直同步让画面呈现等待显示器同步，减少撕裂；实际行为也受所选渲染后端和驱动影响。
Word Wrap自动换行控制文字在行尾的自动换行处理。
Frame Skip / Auto Frame Skip跳帧／自动跳帧Frame Skip 设置跳帧级别（0–2，0 不主动跳帧）；Auto Frame Skip 允许游戏在跟不上目标节奏时自动跳过部分画面绘制。
Advanced Effect原版高级效果控制原版客户端的高级画面效果，与第二页的 Bloom 等 Ephinea 后处理开关分别管理。
Low Res Texture低分辨率纹理降低纹理分辨率，以画面细节换取较低资源占用。
Shadow / Enemy / Map阴影／敌人／地图细节控制原版对应细节等级：Shadow 0–2、Enemy 0–1、Map 0–2。具体视觉差异取决于场景和资源。
Clip Distance绘制距离调整原版场景绘制距离。常规档位为 0–2；更高档位属于扩展范围，保存时程序会提示风险。
Fog Effect雾效实现Vertex Fog 按顶点计算；Pixel Fog 按像素计算；Emulation Fog 使用模拟方式。兼容性和视觉结果与图形后端有关。
Sound Effects / Background Music音效／音乐总开关分别启用或禁用音效、背景音乐；与第一页的音量滑块共同决定最终声音。
Global Focus Sound后台声音游戏窗口失去焦点后继续播放声音。
Font游戏字体选择 Windows 环境中已安装的字体。中文字形覆盖取决于字体；Wine 和 Windows 的可用字体及显示效果可能不同。
Save ID and Password保存登录信息控制游戏是否保存登录 ID 和密码，详见游戏账号保存。
Hardware Log硬件诊断日志调用 DirectX 诊断工具生成硬件信息日志，用于排查兼容性问题。
Save / Cancel保存／取消Save 写入本窗口设置；Cancel 放弃本窗口未保存的修改并返回登录器。

版本与使用范围

本页按 3.5.2 的界面、程序设置读写逻辑和官方更新说明整理。截图保留 Windows 的原生显示效果，仅裁去桌面背景；Wine 下的字体、控件外观和可用渲染后端可能不同。游戏效果也受客户端 DLL、驱动与图形后端影响，截图不代表各项效果已经逐一进行游戏内测试。

需要进一步选择抗锯齿或排查后端兼容性时，继续阅读渲染与图形 API 指南。本专题正文为中文，英文控件名用于界面对照。
